SMS Spam CheckerEnglish only

วางข้อความ SMS ภาษาอังกฤษ แล้วดูว่าโมเดลมองว่าเป็น spam หรือข้อความปกติ พร้อมคำที่ทำให้โมเดลคิดแบบนั้น

1วางข้อความ หรือกดตัวอย่าง
2กด "ตรวจข้อความ"
3อ่านผลและคำที่มีผล
ลองตัวอย่างก่อนก็ได้
หรือวางข้อความของคุณ
กด Ctrl + Enter เพื่อตรวจได้เลย
โมเดลนี้เก่งแค่ไหน (ชุดทดสอบ 742 ข้อความ, spam 93)

ทำงานยังไง
  1. แปลงข้อความเป็นตัวเลขด้วย TF-IDF (นับคำเดี่ยวและคู่คำ)
  2. Logistic Regression ให้น้ำหนักแต่ละคำ แล้วรวมเป็น "คะแนน"
  3. คะแนนมากกว่า 0 = spam, น้อยกว่า 0 = ham

โมเดลนี้เทรนเองจากข้อมูลจริง ไม่ได้เรียก LLM การคำนวณทั้งหมดทำในเบราว์เซอร์ของคุณ ไม่มีการส่งข้อความไปที่ไหน

ข้อจำกัดที่ควรรู้
  • รองรับภาษาอังกฤษเท่านั้น
  • ระบบแสดง ประเมินไม่ได้ เมื่อเป็นภาษาอื่น ไม่พบคำที่รู้จัก หรือยาวเกิน 5,000 ตัวอักษร
  • ออกแบบสำหรับ SMS สั้น ข้อความยาวกว่า 1,000 ตัวอักษรจะมีคำเตือน
  • ข้อมูลเทรนเก่า (ราวปี 2000s) ไม่ได้แทน SMS สแปมปัจจุบัน
  • โมเดลไม่ได้ถูกทุกข้อความ และไม่ได้พิสูจน์ว่าเป็นมิจฉาชีพ
  • "คำที่มีผล" คือน้ำหนักของโมเดล ไม่ใช่เหตุผลจริงของข้อความนั้น
  • คะแนนไม่ใช่ความน่าจะเป็น
